# Modbus 資料格式測試方案

## 目前讀到的原始數值

```
DI01-08: 0 (全部為 0)
DI09: 32662 (signed) → 目前計算: 3266.2°C
DI10: -26624 (signed) = 38912 (unsigned)
DI11: 0
DI12: -14270 (signed) = 51266 (unsigned)
```

## 測試方案

### 方案 1：使用 Unsigned（無符號整數）

如果溫度表回傳的是 unsigned 整數：

```
DI09: 32662 * 0.1 = 3266.2°C (還是太高)
DI10: 38912 * 0.1 = 3891.2°C (不合理)
DI12: 51266 * 0.1 = 5126.6°C (不合理)
```

### 方案 2：調整 Scale 比例

可能 Scale 不是 0.1，試試其他比例：

**Scale = 0.01:**
```
DI09: 32662 * 0.01 = 326.62°C (可能合理，如果是高溫烘箱)
DI10: 38912 * 0.01 = 389.12°C
DI12: 51266 * 0.01 = 512.66°C
```

**Scale = 1:**
```
DI09: 32662 * 1 = 32662°C (不合理)
```

### 方案 3：Swap Bytes（交換高低位元組）

如果位元組順序錯誤：

```
32662 (0x7F86) → Swap → 0x867F = 34431
-26624 (0x9800) → Swap → 0x0098 = 152
-14270 (0xC83E) → Swap → 0x3EC8 = 16072
```

**Swap 後 + Scale 0.1:**
```
DI09: 34431 * 0.1 = 3443.1°C (還是太高)
DI10: 152 * 0.1 = 15.2°C (合理！)
DI12: 16072 * 0.1 = 1607.2°C (可能偏高)
```

**Swap 後 + Scale 0.01:**
```
DI09: 34431 * 0.01 = 344.31°C
DI10: 152 * 0.01 = 1.52°C (偏低)
DI12: 16072 * 0.01 = 160.72°C
```

### 方案 4：嘗試不同的 UnitID

目前使用 UnitID = 255，可能需要：
- UnitID = 1
- UnitID = 2-12 (每個感測器不同)

### 方案 5：檢查暫存器位址

目前讀取 40001 起始，可能需要：
- 從 0 開始
- 從其他位址開始

## 建議測試順序

1. ✅ 測試 Unsigned + Scale 0.01
2. ✅ 測試 SwapBytes + Scale 0.1
3. ✅ 測試 SwapBytes + Scale 0.01
4. ✅ 測試不同 UnitID
